# 决策与变化记录

按需追加已发生的重要决定，不预填不存在的确认。记录 ID 不复用，历史不覆盖；类型与编号见本 skill 的 change-control.md。
普通进度和开放问题写当前任务记录；已启用 plan.md 或 context.md 时分别写入对应产物。本文件只保留决定和变化的追溯依据。
使用后只保留本次实际需要的章节。不适用内容整节删除，禁止保留空标题、模板提示或占位符；必要信息无法确认时标记“待确认”并说明影响，不得为了填满模板而编造内容。
